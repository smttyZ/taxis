# taxis

The layer above the [Lambda Physics Engine](https://github.com/smttyZ/Lambda-Physics-Engine) in [Project Lambda](https://github.com/smttyZ/Project-Lambda): it sets up a simulation, runs it, and collects the results.

**Status:** design not started. This repository is a placeholder until work on [kalon](https://github.com/smttyZ/kalon) and the engine is far enough along to build on.
